# flights_small-dataset
### Dataset Description

This dataset consists of flight tracking logs containing historical flight performance, schedule records, and delay metrics for domestic flights departing from the Pacific Northwest (specifically Seattle-Tacoma International Airport `SEA` and Portland International Airport `PDX`). It spans across 16 distinct raw attributes—including scheduled departure/arrival details, actual flight durations (`air_time`), spatial flight distances, and tracking keys like airline identifiers (`carrier`) and registration tags (`tailnum`)—serving as a comprehensive foundation for building data cleaning pipelines and predictive flight delay models.
